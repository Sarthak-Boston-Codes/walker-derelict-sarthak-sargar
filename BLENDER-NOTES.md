# BLENDER-NOTES.md

Six parts of Blender's interface, in my own words:

## 1. The 3D viewport
The big gray grid area, center-left on screen. The Medkit sits in the center of it — this is where I can actually see and look at my object in 3D.

## 2. The toolbar
The column of icons down the left edge of the viewport: select box, cursor, move (to move the object), rotate, scale, transform, annotate, measure, add cube, and a few others further down.

## 3. The Outliner
The panel listing my object's name — it shows "Medkit" nested under Scene Collection, then Collection.

## 4. The Properties editor
Shows the selected object's location, rotation, mode, scale, and dimensions, with all the specific numbers and measurement options laid out.

## 5. The sidebar (N panel)
Opened with N — has tabs along its edge for Item, Tool, View, Animation, and MCP for Blender (the one I used tonight to connect to Claude).

## 6. The mode selector
Currently set to Object Mode, but the same dropdown also offers Edit Mode, Sculpt Mode, and the paint modes — Vertex Paint, Weight Paint, and Texture Paint.
